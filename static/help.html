Quick start

  1. Start the app: open Terminal, cd ~/Documents/Projects_Folder/ReelStudio, then ./run.sh. Your browser opens at http://127.0.0.1:7860.
  2. Create a Comfy Cloud account and plan (see below), then an API key.
  3. Click Settings, paste the key, click Test key, then Save.
  4. Click Connect in the Comfy Cloud bar at the top. The light turns green.
  5. Pick a character, choose the length and music, click Write the clip prompts, then Make my reel.
  6. When it's done, click Show in Finder. Your reel is in ReelStudio/output/.
  7. Click Disconnect when you're finished for the day.

To stop the app itself, press Ctrl+C in the Terminal window.

Create your Comfy Cloud account

Comfy Cloud runs the Wan 2.2 video model on powerful GPUs, so your Mac doesn't have to.

  1. Go to comfy.org/cloud and click Sign up (or cloud.comfy.org).
  2. Sign in with Google, GitHub or email. New accounts get a few free runs to try it.
  3. Choose a plan at comfy.org/cloud/pricing. You need a paid plan to use the API that this app relies on.
    PlanGood for
    StandardTrying the app and a few reels a month
    CreatorRegular reels, and importing your own models / character LoRAs
    ProHeavy daily use and longer jobs
    Prices and credits change, so check the pricing page. Monthly plan credits don't roll over; top-up credits last longer.
  4. Enter your payment details on Comfy's own site. Reel Studio never sees them.
  5. Optional: open the Wan 2.2 14B image to video template on the website once and run it, to check your account works.

Get your API key

  1. Go to platform.comfy.org → Profile → API keys, signed in with the same account.
  2. Click Create API key, give it a name like Reel Studio Mac, and copy the key. It's shown only once.
  3. In the app: Settings → Comfy Cloud API key → paste → Test key → Save.
Treat the key like a password. It's stored only in ReelStudio/config.json on this Mac and is never uploaded to GitHub (.gitignore excludes it). If it leaks, delete it on platform.comfy.org and create a new one.

Connect / Disconnect and saving credits

The bar at the top right shows the live connection:

LightMeaning
🟢 Connected · idleReady. No credits are being used; Comfy Cloud only charges while a GPU is working on a job.
🟡 Connected · jobs runningA clip is being made on Comfy Cloud. Credits are being used.
⚪ DisconnectedThe app won't send anything to Comfy Cloud.

Connect

Checks your key, turns the light green and opens Comfy Cloud in your browser so you can watch jobs and credits there. The website also opens automatically when a reel starts (at most every 10 minutes). Turn this off in Settings.

Disconnect

Click it twice to confirm. It immediately:

  • cancels every Reel Studio job running or waiting on Comfy Cloud,
  • interrupts the current GPU job,
  • stops all reels in progress, and
  • blocks new jobs until you click Connect again.

Clips that already finished are kept. Later you can press Resume on the reel to continue from where it stopped.

Stop buttons on a reel

  • Stop after this clip: lets the current clip finish (no wasted credits), then stops.
  • Cancel now (stop credits): cancels the current cloud job right away.
There is no Comfy "server" you rent and must switch off. Comfy Cloud is pay-per-use, so when nothing is running, nothing is charged. Disconnect is your emergency brake and a guarantee that nothing new starts.

Characters

Click + Add character or Edit. The start image matters most:

  • one character, full body, facing the camera, vertical (9:16 or close);
  • the background you want in the reel; a plain backdrop gives plain clips;
  • the same outfit you describe in "Outfit in the start image".

For child characters, the app always keeps a cartoon style, modest clothing and playful kid-style moves.

Character LoRA: pick one from the dropdown to lock the character's look. See LoRAs & trigger words.

Make a character from a photo

  1. In step 1, click 📷 Make a character from a photo.
  2. Choose a clear, front-facing photo, then a name, type, style, optional outfit and details to keep (glasses, curly hair, dimples…), and how many versions to make (1–3).
  3. Tick the box to confirm you are the person in the photo or have their permission. For a child, you must be their parent or guardian, or have their permission. The button only works once the box is ticked.
  4. Press Make the character, wait about a minute per version, then Use this one. The character form opens already filled in. Check it and Save.
  • The result is always an illustrated character (3D cartoon, anime, claymation or stylised semi-realistic), never photorealistic. Children are always cartoon-style and modestly dressed.
  • The photo is sent to Comfy Cloud only to draw the character, then deleted from ReelStudio. It is never stored in your library. The drawn versions are saved in the library under "My images", with the date consent was confirmed.
  • This needs an image-edit model on your Comfy Cloud account (Qwen-Image-Edit or FLUX Kontext). Each version uses about 5–9 credits.
  • Please don't use photos of strangers, celebrities or anyone who hasn't agreed.

Image library

The library holds every start image you can use. Pari's images are already in it.

  • Add images: click + Add images in the Image library section (you can pick several PNG/JPG/WEBP files at once), or copy files into ReelStudio/data/library/; they appear automatically.
  • Title and tags: type in the boxes under each picture; they save when you click away. Use the search box to filter.
  • Use as a character's start image: Edit the character → click a picture under "Start image".
  • Use for one reel only: in step 2, choose it under Start image for this reel. The character keeps its usual image.
  • Save a frame from a reel: under a finished clip, click Save last frame to library. This is handy for a new pose.
  • Delete: click Delete twice. Characters that already use the image keep their own copy.
  • Filter: the buttons All · Girls · Boys · Women · Men · Animals · My images show one group at a time.

Character gallery (80 ready-made characters)

  1. Click ✨ Build the character gallery (Comfy Cloud must be connected).
  2. Tick the groups you want: 16 girls, 16 boys, 16 women, 16 men and 16 animals, all invented characters in cartoon, anime, clay, semi-realistic and realistic styles. Children are always cartoon-style and modestly dressed.
  3. The panel shows how many images and about how many credits it will cost (roughly 5–7 credits per image). Press Make the selected images. Each image takes about 15–40 seconds. Stop any time; images already made stay.
  4. Each image is made only once. Press the button again later and it only makes the missing ones.
  5. Under any gallery picture, Make a character opens the character form already filled in (name, type, style, look, outfit, start image). Change anything, then Save.

The app uses the first image model it finds on your Comfy Cloud account: Z-Image Turbo, then Qwen-Image (Lightning), Qwen-Image, then SDXL. To use a different model, open a text-to-image workflow on Comfy Cloud, choose File → Export (API), and save the file as ReelStudio/workflows/t2i_api.json. The app will then use it.

Story mode (short films)

At the top of step 2, switch from 💃 Dance reel to 🎬 Story.

  1. Pick the cast. Tap characters in order (up to 6; 3–4 works best). The first one is the main character. A puppy or kitten you made from the gallery can be a character too.
  2. Write the idea (or tap an example), then choose the length (20 s up to 2½ minutes), setting, tone, narration language (Hindi, English or none) and music. Press Write the story.
  3. Story writer. Choose who writes the story: Automatic, Claude (with an API key), any Ollama model installed on your Mac (each one is listed; start the Ollama app first), or the built-in templates. Larger models (7B and up, e.g. llama3.1:8b, qwen2.5:7b, gemma2:9b) write better stories. Local models can take a minute or two, and progress is shown as they work.
  4. 💡 Give me 3 ideas suggests three story ideas that use your whole cast. Tap one to use it.
  5. ✨ Expand my idea into a full story turns a one-line idea into a complete plan: roles for every character, what the hero wants, the problem, the attempts, the turning point, the ending, the message and 6–10 plot beats. It all lands in the Story builder, where you can edit any of it. Anything you typed there first is kept.
  6. Writing a good idea yourself: WHO (hero) + WANTS (a clear wish) + BUT (a problem) + SO (an attempt that fails, ideally funny) + THEN (a friend or clever idea helps) + FINALLY (a warm ending). Give every character a role and one trait (brave hero, clumsy best friend, wise grandma, cheeky puppy). Keep it visual: big actions, simple props, two or three places. Example: "Pari's new kite gets stuck in Dadi's mango tree. Arjun tries to climb and slips, Bholu barks for help, and Dadi ties a ribbon to a broom to free it. They fly it together at sunset."
  7. Voices: one per speaker. Under Voices there is a row for the 🎙 Narrator and one for every character. Each row has its own voice, pitch (Much lower … Much higher) and speed. Tick Show all voices for 50+ more voices (needs internet once). The Multilingual voices (Ava, Emma, Andrew, Brian) can speak Hindi too, which gives Hindi stories more than two different voices. Press ▶ to hear it. Sensible voices are picked for you: a higher voice for children, a male or female voice for adults, and a very high voice for animals.
  8. Check the shot list. Every shot is a card you can edit:
    • How it's made. New shot from a start keyframe is a normal cut. Start + end keyframes is best whenever hands touch something (picking up, giving, hugging, catching). Continue previous shot carries on with no cut.
    • What happens, second by second: 0–2 s, 2–4 s, 4–5 s, one simple movement each.
    • Eyes look at… and Hands do…: say which hand, which object and where it is. The eyes should look at an object before the hand reaches it.
    • Props: big and simple (ball, balloon, kite, flower, gift box, puppy). Yellow warnings appear for things AI video handles badly (pens, phones, spoons, laces, keys…) and for shots with too many actions.
    • Spoken lines: up to 3 per shot. Choose who says each line (Narrator or a character) and keep each line short (about 12 words). Lines in one shot are spoken one after another. If they're longer than the shot, it is slowed a little or held so the words fit. Sound effect: press ▶ to hear it.
  9. 1 · Make keyframes. The app draws the first picture of each shot (and the last picture for start+end shots) on Comfy Cloud, using your characters' images so faces and outfits stay the same. For each keyframe: Redo, Upload your own picture, or Approve. Keyframes are cheap; fix them before making video.
  10. 2 · Make the video. One 5-second video per shot, then the app joins them with cuts, adds the voice, sound effects and soft music (the music dips under the voice). If a narration line is longer than its shot, the shot is slowed a little or held so the words fit.
  11. Long stories (1–2½ minutes). The story is planned as scenes first, then each scene's shots are written with the story so far in mind. This works best with a Claude API key or Ollama; the built-in writer reuses simple scenes. A 2-minute story is about 24 clips and 30–40 keyframes: roughly 1,100–1,500 credits and 1–1½ hours of cloud time. Tick Compact view to hide the detail fields, and use Stop or Resume whenever you like, because finished shots are kept.
  12. Finished. You get the clean video, a copy with subtitles drawn on, and a .srt subtitle file. Tick Preview with subtitles to compare, then download the one you want. Change the voices or music lets you change any speaker's voice or pitch and re-makes the sound for free (no cloud).

Voices: Microsoft Edge neural voices (installed automatically the first time; they need internet), including Hindi (Swara, Madhur) and child-like English voices (Ana, Maisie). Without internet, the Mac's own voices are used. Your own sound effects: put WAV/MP3 files in ReelStudio/data/sfx/.

Keyframe engine: Qwen-Image-Edit 2509 (up to 3 character images per picture), then Qwen-Image-Edit, then FLUX.1 Kontext; otherwise the picture is drawn from text only. To use your own edit workflow, export it from Comfy Cloud (File → Export (API)) as workflows/edit_api.json.

Credits counter

  • The green pill at the top (💳 … credits left) is your live Comfy Cloud balance, read from Comfy's billing API about once a minute and after every job. Click it to refresh. Hover to see the split: plan credits, top-up credits, spent this month, and what this app used.
  • It turns yellow below 600 credits and red below 150.
  • If Comfy does not return a balance for your key, the pill turns grey and shows the app's own estimate of credits used this month. Your exact balance is always on Comfy Cloud under profile menu → Manage plan → Credit history.
  • Before you press Make my reel, the plan shows This reel: about N credits for the chosen length and Turbo settings, and warns you in red if your balance is too low. Estimates start from typical times and learn from your own clips after a few runs.
  • Every clip's log line shows about how many credits it used. Comfy's rate is $1 = 211 credits, and GPU time costs about 0.266 credits per second.

LoRAs and trigger words

A LoRA is a small add-on file trained on one character (or style). It teaches Wan 2.2 exactly what the character looks like, so the face, hair and outfit stay identical in every clip and every reel. That's the best fix for "the face changes a little".

A trigger word is a made-up word (like p4ri) that the LoRA was trained with. Putting it at the start of the prompt switches the LoRA's look on. A trigger word does nothing on its own: the LoRA files must be loaded too. Reel Studio does both for you once the LoRA has files.

Dropdown entryWhat it does
No character LoRAUses only the start image and description. Fine for most reels.
Lightning 4-step (Turbo)A speed LoRA built into the workflows, controlled by the Turbo tick box. No trigger word.
Pari character LoRA (not trained yet)A ready-made entry for Pari with trigger p4ri. Inactive until you add the trained files.
Your own LoRAsAdd them with Manage LoRAs.

Make and use a character LoRA

  1. Make 12–20 training images of the character: different angles (front, three-quarter, side), close-ups and full body, 2–3 outfits, different expressions and backgrounds. Keep the face identical. Add them to the library.
  2. Write a caption per image starting with the trigger word, e.g. p4ri, close-up, smiling, plain background.
  3. Train a Wan 2.2 14B LoRA, for example with fal.ai's "Wan 2.2 14B Image Trainer" (upload a ZIP of images + captions, set the trigger, about 1,000 steps), Civitai's trainer, or AI Toolkit on a rented GPU. You get two files: high-noise and low-noise.
  4. Put the files on Hugging Face (a private repo is fine) or Civitai.
  5. Import into Comfy Cloud (Creator plan or higher): Models → Import → paste each file's download link → folder loras. For a private repo, first add your Hugging Face token under Comfy Cloud Settings → Secrets.
  6. In Reel Studio: Manage LoRAs → Edit the entry → type the exact two file names as shown in Comfy Cloud → My Models → Save. Then pick it in the character's LoRA dropdown.
Strength 0.8–1.0 is usual. Too high can look stiff; too low can let the face drift.

Plan and make a reel

  1. Length: 10–30 s. Every 5 s is one clip, generated separately.
  2. Setting and Mood: describe the place and the song's feel.
  3. Turbo (recommended): about 1–2 min per clip. Off: about 10 min per clip, slightly more detail. The chip next to the tick box shows Turbo: ON, Turbo: OFF or Turbo: unavailable (the workflow is missing the switch or the lightx2v LoRAs; hover to see why). Your choice is remembered for the next reel.
  4. Turbo check: if Turbo is off when you press Make my reel, Resume or Redo from this clip, the app stops and asks first. Enable Turbo and start switches it on for that reel and as your default, then starts. Keep it off starts in slow mode. Cancel starts nothing, so no credits are used.
  5. Upscale: exports 1080 × 1920 for Instagram.
  6. Write the clip prompts: read and edit each clip's text.
  7. Make my reel: watch each clip go Uploading → On Comfy Cloud → Done. Hover a finished clip to preview it.

How clips are chained

Wan 2.2 makes about 5 seconds at a time. The app joins clips so the motion looks continuous:

  • Chained: a clip starts from the previous clip's last frame. Its duplicate first frame is trimmed when joining.
  • End on character image: the clip uses first-and-last-frame mode and must finish on the original picture. It's always on for the last clip, so the character ends looking exactly like herself.
  • Restart from character image: the clip starts from the original picture again. Reels of 20 s or more do this every third clip, so the face doesn't slowly drift. The clip before it ends on the same picture, so the cut is invisible.

Dance that follows the music

Pick My song file before pressing Write the clip prompts. The app listens to the song first:

  • Tempo and beats. The song panel shows its BPM. Tick marks on top are the bars (downbeats).
  • Energy. Bar colours: grey = calm, gold = medium, red = high. The pink box is the part of the song your reel uses. Click the graph to move it there, or drag the box. ◀ bar / bar ▶ move it by one bar. Use the liveliest part jumps to the most energetic stretch and plays it straight away.
  • Hear the selection. ▶ Play selected part plays exactly the part your reel will use, and stops at its end (tick Loop to repeat it). A black line moves across the graph as it plays. Moving the box while it plays restarts from the new start. With Start exactly on a beat, the start snaps to the nearest bar.
  • Moves match energy. Calm parts get flowing arms and sways; medium parts get bouncy steps, claps and twists; high parts get jumps, fast spins and big arm throws. Moves never repeat within a reel, and each clip uses a different body part from the one before.
  • Lyrics become gestures. Paste the lyrics (one line each; [0:12] times at the start are optional), or press Write the lyrics for me (Whisper). Words like clap/taali, moon/chand/sky, dil/love/heart, aaja/come, nacho/dance, rain/baarish turn into matching gestures. Each clip card in the plan shows its energy, the lyric line and the gesture chosen. The lyrics themselves are never put in the video prompt.
  • Whisper runs on your Mac. The first time, it installs faster-whisper and downloads a model (about 150 MB), which takes a few minutes. Song vocals over loud music are hard to hear, so always check and fix the lines it writes. Choose the language (Hindi, English, …) for better results.
  • Dynamic Turbo (on by default): the first 2 of 6 steps run without the speed LoRA, so movements come out bigger and livelier. It adds about 1 minute and a few credits per clip. Untick it for the fastest, cheapest clips.
  • Beat sync (on by default): when joining, the app finds the moments where the dance "hits" and speeds each clip up or down by up to 10% so more of those hits land on beats. The log shows the before and after numbers, for example "39% of the dance accents land on a beat (was 28%)".

Tip: you can still type extra wishes in "Mood or song notes" (for example "bhangra style" or "lots of spins"), and edit any prompt before making the reel.

Fix a clip or change the music

  • Redo from this clip: remakes that clip and every clip after it (later clips depend on its last frame).
  • Resume: continues a stopped or failed reel from the first unfinished clip.
  • Change the music → Remix music: new music in seconds, no cloud credits used.
  • Past reels: open any earlier reel to watch, redo or remix it.

Better prompts (Claude / Ollama)

The app writes prompts with the first option available:

  1. Claude: add an Anthropic API key in Settings (from console.anthropic.com). Best results.
  2. Ollama: if Ollama is running on your Mac, tick "Use Ollama" and pick a model.
  3. Built-in: ready-made dance moves; always works offline.

You can always edit any prompt before pressing Make my reel.

FAQ

Does Comfy Cloud charge me while the app is open?

No. Comfy Cloud charges only while a GPU is working on a job. An open app, or a "connected" light with no jobs, uses no credits.

Can I close my laptop while a reel is being made?

The clip being made keeps running on Comfy Cloud, but the app needs to be running to start the next clip and download results. Keep the Mac awake and plugged in, or press Resume later.

Why 5-second clips?

That's what Wan 2.2 generates well in one pass. Longer reels are chained clips, which also lets you redo just one part.

Can I make adult or animal characters?

Yes. Choose the type when adding the character. The child safety rules apply only to child types.

Is my data uploaded anywhere?

Only the start images and prompts go to Comfy Cloud to make clips, and prompts go to Claude if you set a key. Everything else stays on your Mac.

Do I need to label the reels as AI?

Yes. On Instagram, switch on the AI label under Advanced settings when you post.
