📷 Make a character from a photo

ReelStudio draws an original illustrated character that looks like the person: same face shape, hair, skin tone and smile, in the style you choose. It is never photorealistic, so it can't be mistaken for a real photo or video of them.

A clear, front-facing photo works best

Privacy: the photo is sent to Comfy Cloud only to draw the character, then deleted from ReelStudio. It is never added to your library. Children are always drawn in a cartoon style. Each version uses about 5–9 credits.

Turbo mode is off

Without Turbo, each 5-second clip takes about 8–12 minutes on Comfy Cloud and uses several times more credits. With Turbo it takes about 1–2 minutes, with slightly softer detail.

Character LoRAs

A LoRA is a small add-on model trained on one character. Its trigger word (for example p4ri) is put at the start of every prompt to switch the LoRA's look on. A trigger word does nothing without its LoRA files, so add the file names exactly as they appear in Comfy Cloud → Models → My Models (Creator plan or higher).
